# Installation

Le correctif s’applique au dernier projet « Altherya_Arene_Boutons_Complets » (version 18). Copiez le contenu du dossier Altherya_V0_8_10 dans votre projet et acceptez les remplacements. Le projet complet comprend aussi tous les assets.

Conservez vos paramètres .env et votre base de données. Publiez les changements avec votre procédure GitHub habituelle, puis redéployez dans Coolify. Pour construire localement : npm ci puis npm run build dans apps/game.
