# Installer les menus reconstruits

Cette archive est une mise à jour cumulative du projet Altherya existant.

1. Sauvegarder le projet et les données.
2. Copier le contenu du dossier Altherya_V0_8_10 à la racine du projet en remplaçant les fichiers correspondants.
3. Conserver les fichiers .env, secrets, volumes et bases de données.
4. Reconstruire et redéployer dans Coolify, puis recharger l’Activity Discord.

Les images seules ne suffisent pas : le nouveau code de composition et le composant de forge doivent être compilés avec le projet. Aucune remise à zéro du tutoriel ou des joueurs n’est nécessaire.
