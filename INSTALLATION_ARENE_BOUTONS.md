# Installation

Le correctif s’applique à la dernière version « Altherya_Menus_Placement » (version 17). Copiez le contenu de Altherya_V0_8_10 dans votre projet puis acceptez le remplacement. Le projet complet contient tous les assets et sources.

Conservez vos fichiers .env et votre base de données. Publiez la mise à jour sur GitHub avec votre procédure habituelle et redéployez dans Coolify. Pour vérifier localement : npm ci puis npm run build dans apps/game.
