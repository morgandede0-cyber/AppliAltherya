# Audit machines à sous

- Construction TypeScript/Vite réussie.
- Compilation syntaxique des 85 modules Python réussie.
- Suite interface : 125 tests réussis, aucun échec.
- Parcours navigateur : 48 contrôles réussis avec API réelle et base temporaire, sur 1440×900, 1186×570, 390×844 et 320×568. Vérifications du levier, de la mise, du verrouillage, des arrêts successifs, des symboles finaux, du solde, du menu des règles et du retour à la salle. Les rouleaux restent alignés et leurs symboles centrés ; résultat et actions ne se chevauchent pas sur mobile.
- Suite serveur : 232 tests exécutés. 231 sont passés au premier passage. Le test de l’index statique a rencontré un fichier absent pendant la construction simultanée du client ; après construction, les 4 tests de la passerelle ont été relancés et sont tous passés. Aucun échec restant.
- Tests de gains : chaque triple, les deux sept, les symboles mélangés et les révisions empêchant un double règlement. La table des gains publiée correspond aux constantes du moteur.
- Inspection visuelle finale PC, mobile et paysage mobile ; découpes du levier et des cinq symboles contrôlées.

Les règles et probabilités du casino sont conservées. Ni les récompenses du tutoriel ni les prix des outils ne changent. Le blackjack, la roulette et les autres menus sont conservés. Les tests utilisent des bases temporaires ; pas de test sur la base de production, le Gold Oddium en production ou le client Discord de production. Les animations affichent le résultat serveur ; le décor et le lion restent fixes.
