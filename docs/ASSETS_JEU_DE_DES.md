# Assets des dés

Images produites par la génération d’images intégrée :

- `apps/game/public/assets/dice/table.png` : à partir de la maquette approuvée, conserver exactement la taverne, le renard, la lumière, les chopes, le gobelet, le plateau et ses cadres ; retirer les deux dés, leurs ombres, les textes variables, les jetons de mise et les libellés des commandes ; reconstruire le cuir et le bois et conserver le titre JEU DE DÉS.
- `apps/game/public/assets/dice/ivory.png` : texture carrée répétable d’ivoire poli ancien, crème chaud avec pores et mouchetures très subtils, lumière uniforme, sans points, symboles, bordure ni texte.

Ces spécifications constituent les prompts de production. La géométrie arrondie, les points exacts, les creux, les reflets et les ombres sont rendus en code pour conserver une rotation réelle et afficher les bons résultats. Les jetons et contrôles réutilisent l’atlas du casino existant.
