# Salle clandestine : enseignes interactives

Les cinq enseignes et le retour sont isolés du décor et deviennent les boutons. Le décor sans enseignes est distinct ; les pixels des panneaux existants sont conservés dans des découpes SVG transparentes. Le survol se limite à une légère variation de luminosité, sans grand cadre jaune.

Les variantes PC et mobile sont positionnées sur leurs décors respectifs. Les zones tactiles font au moins 44 pixels. Navigation clavier, portefeuille, durée d’accès et règles des jeux sont conservés.

Déployer les sources et assets puis lancer la construction habituelle. Aucune migration de données ni variable supplémentaire.
