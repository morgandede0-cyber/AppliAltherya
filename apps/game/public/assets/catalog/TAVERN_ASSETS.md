# Assets des jeux de taverne

`tavern-games.webp` est un atlas RGBA 1536 × 1024 créé avec l'outil intégré de génération d'images, à partir du style du menu `assets/menus/games.webp`. Les limites et associations sont définies dans `src/ui/game-art.ts` : pièce portrait, pièce fleur de lys, cadre sans texte, pierre, feuille, ciseaux. Les libellés, valeurs et états restent dans le code.

Prompt de génération :

> Create a production GAME SPRITE ATLAS, single transparent PNG, landscape 1536x1024, precise regular 3 column by 2 row grid, each cell 512x512. Reference image role: stylistic reference and object appearance only, keep its rich illustrated medieval gold and royal-blue fantasy game UI style. Six INDEPENDENT objects, separated, centered in their cells, with generous 40px transparent margins. TOP LEFT: one full circular gold coin, portrait of crowned medieval king, front-on circle with ornate gold rim, NO overlap with other coins. TOP MIDDLE: one full circular gold coin, fleur-de-lis emblem, front-on circular rim, no overlap. TOP RIGHT: EMPTY medieval blue-and-gold game card frame inspired by the reference, gold carved border blue diamond corner jewels, royal blue textured empty interior, small EMPTY royal blue caption ribbon at bottom. No baked letters, no dice inside. BOTTOM LEFT: a single grey stone matching the reference, isolated. BOTTOM MIDDLE: a single green leaf lying on a small pale parchment, isolated; NO stone or scissors next to it. BOTTOM RIGHT: a pair of ornate golden scissors matching the reference, isolated, NO paper or stone. True transparent background around ALL objects, no blue rectangular background for coins or symbols. No text, no labels, no numbers, no watermark. Entire object contours intact and smooth. NOT a mockup, real reusable isolated sprite atlas for an interactive game.
