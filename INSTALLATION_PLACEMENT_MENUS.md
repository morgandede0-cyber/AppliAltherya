# Installation

Le correctif s’applique à la dernière livraison « Altherya_Menus_Interactifs_Transparents » (version 16). Copiez le contenu du dossier Altherya_V0_8_10 dans votre projet et acceptez le remplacement des fichiers. Le projet complet comprend aussi tous les assets.

Conservez vos paramètres .env et votre base de données. Mettez à jour GitHub avec votre procédure habituelle, puis redéployez dans Coolify. Pour construire localement : npm ci puis npm run build dans apps/game.
