# Suppression du bouton Ouvrir le journal

Le bouton Ouvrir le journal est retiré de l’onglet Missions du suivi des quêtes. Les accès directs au contrat et à l’expédition restent disponibles. Les autres catégories et menus sont conservés.

Pour installer le correctif léger : extraire le ZIP et copier le dossier apps dans la racine du projet existant, en remplaçant les fichiers concernés. Envoyer les changements sur GitHub puis redéployer dans Coolify. Le projet complet contient déjà cette correction.

Contrôles : compilation TypeScript/production réussie ; six tests du suivi des quêtes réussis. Le test navigateur contrôle également l’absence du bouton et le retour à la catégorie Aventure, sur PC et mobile.

Aucune modification des données, récompenses, prix, sauvegardes ou règles de quête.
